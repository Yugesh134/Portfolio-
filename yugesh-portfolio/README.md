# 🚀 Yugesh Kumar — Modern Developer Portfolio

A premium and fully responsive **Developer Portfolio Website** built using **React.js**, **Vite**, and **Tailwind CSS**.

This portfolio showcases:
- modern UI/UX
- reusable component architecture
- smooth animations
- custom cursor effects
- responsive layouts
- interactive project showcase

Designed with a clean **Amber + Dark** theme inspired by modern SaaS and developer portfolios.

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/Yugesh134/Portfolio-.git
```

---

## 2️⃣ Go To Project Folder

```bash
cd yugesh-portfolio
```

---

## 3️⃣ Install Dependencies

```bash
npm install
```

---

## 4️⃣ Start Development Server

```bash
npm run dev
```
